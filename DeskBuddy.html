Desk Buddy

A desk companion that shows GPS-synced time, barometric pressure, and altitude on a color TFT screen, with touch controls and audio. I designed and tested it one component at a time, then integrated everything on a single Arduino Uno.

Platform
Arduino Uno
Sensors
BMP280, GPS
Display
2.8" ILI9341 TFT, touch
Status
Integrated build tested

Hardware

  • Arduino Uno with an Elegoo 2.8" TFT shield (ILI9341, touch)
  • BMP280 pressure and temperature sensor on hardware SPI
  • Goouuu GT-U7 GPS module for time, date, altitude, and satellite fix
  • PAM8302A amplifier and speaker for tones and chimes

Software

Written in Arduino C++ with MCUFRIEND_kbv for the display, Adafruit GFX and TouchScreen, Adafruit BMP280, and TinyGPSPlus for NMEA parsing. The final sketch is organized around one rule: the GPS serial buffer holds only about 66 ms of data at 9600 baud, so the loop must read GPS on every pass and keep each drawing job short.

Design decisions from testing

  • Serial buffer conflict: the display redraws were causing GPS data loss. Full-screen redraws blocked about 200 ms per frame, which was far longer than the buffer could absorb.
  • Per-character updates in quiet gaps: the GPS sends a burst of data each second, then goes quiet for about 500 ms. Drawing only changed characters, and only during that silence, eliminated data loss in the short tests.
  • Flash memory: the display library was consuming most of the Uno's 32 KB of flash. Trimming unused controller support brought the full build to about 95% of flash, leaving about 1,480 bytes free.
  • Pressure to weather: the BMP280 reads absolute pressure, so the display needs an elevation correction to show a sea-level value.

Open items

  • Fit input DC-blocking capacitors on the audio amplifier, then retest sound quality.
  • Run a 30 to 60 minute soak test of the full build, checking for resets, heat, drift, and touch dropouts.
  • Find the cause of the intermittent GPS data loss in long runs.
  • Optional: wire the GPS PPS pin for sub-second time accuracy.
